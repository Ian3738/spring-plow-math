# 春耕未來・數造共好

在知識翻新環境下以 AI 協作之教師專業增能計畫。
徐道寧教授數學教育與人文關懷實踐獎助．團體組．國立清華大學教育與學習科技學系。

## 本站內容

示範單元「圓的概念」（康軒版三年級下學期第六單元）之通用學習設計，共七頁：

| 頁面 | 內容 |
|---|---|
| 總覽 | 單元定位、Q20 選答率、三種錯誤類型、單元範圍、九宮格總覽 |
| 數學本質 | 圓與圓區域的定義、圓心不屬於圓、半徑的四種描述、弦與直徑、半徑直徑關係 |
| UDL 設計 | 九項 Guideline 逐格展開：做法、材料、時間、對應障礙點、檢核方式、對應節次 |
| 教學流程 | 五節課，每節 40 分鐘逐段拆解，含教師用語與學習差異安排 |
| 教學鷹架 | 試題分析報告教學建議之四項鷹架，另附 46% 迷思的專門處理 |
| AI 協作 | 本單元的限制語法、六個可照抄的 AI 指令、產出後的檢核清單 |
| 評量檢核 | 自編檢核題、學生自我檢核表、前後測設計、事先寫明的無效判定條件 |

數學式以 KaTeX 渲染；四個互動作圖以 GeoGebra 呈現，預設顯示靜態圖，按下按鈕才載入。

## 修改方式

各頁內容在 `src/`，只含 `<section>` 區塊。頁首、導覽、頁尾與腳本由 `build.py` 統一套上：

```
python3 build.py
```

改了 `assets/style.css` 或 `assets/site.js` 之後，把 `build.py` 裡的 `V` 加一，避免瀏覽器快取舊版。

## 設計立場

不改變學生必須學會的課綱核心能力，改變的是知識傳遞的路徑。
課程調整的順序為優先「替代」，其次「重整／分解」，最後才考慮「簡化／減量」。

本站同時是通用設計的示範品：全站符合 WCAG AA，圖形皆附口述文字，數學式附 MathML 供螢幕報讀，
不以顏色單獨傳達訊息，深淺主題各自配色，且刻意不另設「視障模式」，
理由是另立專屬模式即為特定群體作出特別設計，與通用設計的定義相悖。
