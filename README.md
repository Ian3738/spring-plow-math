# 春耕未來・數造共好

在知識翻新環境下以 AI 協作之教師專業增能計畫。
徐道寧教授數學教育與人文關懷實踐獎助．團體組．國立清華大學教育與學習科技學系。

## 本站內容

示範單元「圓的概念」（康軒版三年級下學期第六單元）之通用學習設計。
含九項 Guideline 設計表、四項教學鷹架，以及學力檢測 Q20 試題分析所揭示的教材設計層級困難。

## 設計立場

不改變學生必須學會的課綱核心能力，改變的是知識傳遞的路徑。
課程調整的順序為優先「替代」，其次「重整／分解」，最後才考慮「簡化／減量」。

本站同時是通用設計的示範品：全站符合 WCAG AA，圖形皆附口述文字，
不以顏色單獨傳達訊息，深淺主題各自配色，且刻意不另設「視障模式」，
理由是另立專屬模式即為特定群體作出特別設計，與通用設計的定義相悖。

## 資料來源

國立臺中教育大學測驗統計與適性學習研究中心（2023）。
112 年度縣市學生學習能力檢測：數學三年級施測結果報告。

Q20 之通過率與選項分布為全體參與縣市之受測學生（十縣市，到考 49,031 人）。
空間與形狀 42.4% 為新竹市 201 個班級之班級答對率平均。

設計框架依 CAST (2024). Universal Design for Learning Guidelines version 3.0.
